# Сквозное домашнее задание

## Результат

К концу курса студент готовит воспроизводимый мини-проект научной визуализации: данные, код, набор обоснованных графиков и итоговую композицию, пригодную для отчёта, статьи или презентации.

## Обязательные части

1. Научный или инженерный вопрос, который решается визуализацией.
2. Описание источника, структуры, единиц измерения и ограничений данных.
3. Воспроизводимая загрузка и подготовка данных.
4. Не менее трёх осмысленных 2D-представлений, включая одну сравнительную или распределительную визуализацию.
5. Один продвинутый модуль по выбору и по смыслу данных: 3D/контуры/векторное поле, анимация/временной ряд или интерактивный дашборд.
6. Для пространственных или объёмных данных — сцена ParaView. Если такие данные не подходят предметной области, допускается учебный набор преподавателя.
7. Итоговая векторная композиция в Inkscape на основе SVG из Matplotlib.
8. Репозиторий с инструкцией запуска, фиксированным окружением и понятной структурой.

## Этапы

| Этап | Срок сдачи | Артефакт |
|---|---|---|
| 0. Старт | практикум 1 | окружение, репозиторий, черновой выбор данных |
| 1. Данные | практикум 2 | паспорт данных, загрузка, очистка, NumPy/Pandas |
| 2. Базовый рисунок | практикум 3 | Figure/Axes, подписи, шкалы, легенда, экспорт |
| 3. Система 2D-графиков | практикум 4 | сравнение типов графиков и мультипанельная фигура |
| 4. Геометрия/динамика | практикум 5 | 3D, контуры, поле или анимация по смыслу данных |
| 5. Интерактивность | практикум 6 | временной сценарий, интерактивный элемент или Dash |
| 6. Объёмные данные | практикум 7 | ParaView pipeline и сохранённый результат |
| 7. Публикационная композиция | практикум 8 | SVG/Inkscape, финальная ревизия проекта |

## Минимальный стандарт сдачи этапа

- результат запускается на машине преподавателя по инструкции;
- в репозитории нет абсолютных путей и локальных паролей/токенов;
- исходные данные не дублируются без необходимости, крупные файлы описаны ссылкой;
- график отвечает сформулированному вопросу, а не просто демонстрирует тип диаграммы;
- оси, единицы, легенды и источники данных указаны;
- студент может объяснить ключевые решения в коде и дизайне.
