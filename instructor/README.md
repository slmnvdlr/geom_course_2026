# Материалы преподавателя

Этот каталог не относится к рабочей области студента и хранит методические материалы курса:

- `practical-plan.md` и `practical-plan.docx` — план восьми практических занятий;
- `submission-rules.md` — регламент самостоятельной работы и индивидуальной сдачи;
- `course-project.md` — полное описание сквозного проекта;
- `smoke_test.py` — служебная проверка окружения.
