# Научная графика и геометризация областей

Это рабочий репозиторий студента. Здесь вы будете хранить домашние задания, код сквозного проекта, небольшие наборы данных и итоговые изображения.

## С чего начать

1. Получите собственную копию репозитория способом, который указал преподаватель.
2. Клонируйте **свой** репозиторий на компьютер.
3. Откройте папку проекта в VS Code, PyCharm или другом редакторе.
4. Выполните [ДЗ №0](homeworks/hw00/README.md).
5. Перед каждой сдачей проверьте, что изменения закоммичены и отправлены на GitHub.

## Структура репозитория

```text
homeworks/     отдельная папка для каждого домашнего задания
project/       сквозной проект по научной визуализации
src/           переиспользуемые функции и модули
data/          небольшие исходные и обработанные данные
figures/       изображения, созданные кодом
exports/       итоговые SVG, PDF и другие материалы
environment/   инструкции и файлы окружения
```

Материалы преподавателя находятся в каталоге `instructor/` и не нужны для выполнения ДЗ №0.

## Домашние задания

| Задание | Тема | Результат |
|---|---|---|
| [ДЗ №0](homeworks/hw00/README.md) | Git, Python, виртуальное окружение | `hello.py`, `requirements.txt`, первый push |

Каждое следующее задание оформляется в собственной папке:

```text
homeworks/hw00/
homeworks/hw01/
homeworks/hw02/
```

## Основной цикл работы

```text
git pull
# выполнить и проверить задание
git status
git add .
git commit -m "Complete homework 0"
git push
```

Сообщение коммита должно коротко описывать результат. Не используйте сообщения `update`, `fix` или `123`.

## Что нельзя загружать

- каталог `.venv`;
- пароли, токены и другие секреты;
- системные и временные файлы;
- большие исходные данные без согласования с преподавателем;
- файлы, которые не относятся к курсу.

## Если возникла ошибка

Перед обращением за помощью подготовьте:

- полный текст команды;
- полный текст ошибки;
- вывод `python --version`;
- название операционной системы;
- ссылку на последний коммит.
