# Практические занятия по курсу «Научная графика и геометризация областей»

Репозиторий содержит план восьми практических занятий, правила самостоятельной работы и минимальное окружение для курса.

## Основная идея курса

Каждый студент ведёт один сквозной проект на собственном или предложенном преподавателем наборе научных данных. Между занятиями студент выполняет крупный содержательный этап, а на паре:

1. группа разбирает общие затруднения;
2. студенты продолжают работу и исправляют замечания;
3. каждый студент индивидуально сдаёт текущий этап преподавателю.

Практическое занятие 1 проходит до первой лекции и не требует знания Python: на нём настраивается рабочее пространство, проверяются инструменты и создаётся каркас проекта.

## Быстрый старт

```text
python -m venv .venv
.\.venv\Scripts\Activate.ps1  # Windows PowerShell
python -m pip install --upgrade pip
python -m pip install -r environment/requirements-core.txt
python starter/smoke_test.py
```

На macOS/Linux команда активации: `source .venv/bin/activate`.

После успешного запуска в каталоге `figures/` появится файл `environment-check.png`.
