# Научная графика и геометризация областей

Это рабочий репозиторий курса. Здесь находятся домашние задания и заготовки для сквозного проекта.

Если вы раньше не работали с Git и GitHub, начните с раздела ниже. Команды нельзя выполнять механически: важно понимать, где находится ваша работа и куда отправляются изменения.

## Что такое Git, GitHub и репозиторий

### Git

**Git** — программа для контроля версий. Она запоминает последовательность изменений в проекте. Благодаря Git можно увидеть, когда и зачем был изменён файл, вернуться к предыдущей версии и не хранить папки с названиями `final`, `final2` и `точно_final`.

Git работает на вашем компьютере. Команды `git status`, `git add` и `git commit` относятся к локальной папке проекта.

### GitHub

**GitHub** — сайт, на котором хранятся удалённые Git-репозитории. Он нужен, чтобы:

- хранить резервную копию работы;
- отправлять преподавателю ссылку на задание;
- переносить проект между компьютерами;
- видеть историю коммитов;
- работать с одним проектом вместе с другими людьми.

### Репозиторий

**Репозиторий** — папка проекта вместе с историей изменений Git. Внутри локального репозитория находится скрытая служебная папка `.git`.

У каждого студента будут две связанные копии:

1. **Удалённый репозиторий** — находится на GitHub в аккаунте студента.
2. **Локальный репозиторий** — находится на компьютере студента.

Изменения сначала сохраняются локально командой `git commit`, а затем отправляются на GitHub командой `git push`.

## Основные слова

| Термин | Что означает |
|---|---|
| **Fork** | создать в своём аккаунте GitHub личную копию репозитория курса |
| **Clone** | скачать репозиторий с GitHub на компьютер вместе с историей Git |
| **Commit** | сохранить законченный этап работы в локальной истории |
| **Push** | отправить локальные коммиты на GitHub |
| **Pull** | получить с GitHub изменения, которых ещё нет на компьютере |
| **Repository** | папка проекта и история её изменений |

## Как будет устроена работа

```text
Репозиторий курса
        ↓ Fork
Личный репозиторий студента на GitHub
        ↓ Clone
Локальная папка на компьютере
        ↓ Commit и Push
Результат появляется в личном репозитории студента
```

Студент не отправляет домашнее задание непосредственно в репозиторий преподавателя. Сначала нужно сделать Fork, а затем клонировать **свой** репозиторий.

## Структура репозитория

```text
homeworks/     отдельная папка для каждого домашнего задания
project/       сквозной проект по научной визуализации
src/           переиспользуемые функции и модули
data/          небольшие исходные и обработанные данные
figures/       изображения, созданные кодом
exports/       итоговые SVG, PDF и другие материалы
environment/   дополнительные инструкции по окружению
```

## Правила оформления

- каждое задание выполняется в отдельной папке `homeworks/hwNN`;
- законченный этап оформляется отдельным содержательным коммитом;
- перед сдачей нужно выполнить `git push` и проверить файлы на GitHub;
- `.venv`, пароли, токены и большие исходные данные загружать нельзя;
- преподавателю отправляется ссылка на личный репозиторий студента.
